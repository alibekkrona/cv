# Arsen Abduraimov - CV and Engineering Portfolio

This repository is the working source for:

- the master CV;
- role-specific CV variants;
- engineering case studies;
- selected portfolio demonstrations;
- GitHub profile material.

## Structure

- `projects/` - case studies and demonstration projects published with the repository.
- `docs/` - local planning and source documentation excluded from Git.
- `drafts/` - local drafts excluded from Git.

## Repository Rule

Everything committed to this repository is intended to be public.
Local planning materials remain under ignored directories and are never added
to Git history.
