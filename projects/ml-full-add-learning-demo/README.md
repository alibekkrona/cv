# ML Full Addition Learning Demo

An inference-ready demonstration of a compact Transformer trained to add two
ordinary non-negative decimal integers.

The application runs the packaged neural checkpoint directly on CPU. The
answer shown as **Model result** is generated by the network; the ordinary
Python sum is calculated separately and displayed only as a verifier.

The research was informed by step-by-step compositional-capability work: a
larger behavior is represented as an ordered sequence of learned state
transformations. This public package intentionally exposes only the resulting
addition capability, not the private training documents or internal state
program.

## Result

| Measurement | Result |
| --- | ---: |
| Model parameters | `398,848` |
| Decimal operand range | `0..9,999,999` |
| Selected checkpoint | step `126,000` |
| Full sealed validation | `99.44%` exact |
| Independent Cartesian stress audit | `100%` exact (`3,984/3,984`) |
| Cartesian behavior strata | `498` |

The full sealed validation and targeted stress audit are separate evaluation
scopes. The latter crosses operand width, carry-chain placement and length,
sparsity, termination and operand orientation.

## What It Demonstrates

- reusable digit tokens representing millions of possible integers;
- one shared causal Transformer generating a decimal result;
- learned handling of multi-position carries and a new high-order digit;
- direct greedy inference without an external model service;
- a deterministic verifier kept separate from the neural prediction.

The package does not contain the training corpus, dataset generator, optimizer
state, research manifest, internal function labels or intermediate model
states.

## Architecture

```text
decoder-only causal Transformer
layers:                    2
model width:               128
attention heads:           4
feed-forward width:        512
activation:                ReLU
normalization:             post-LayerNorm
position encoding:         fixed sinusoidal
total parameters:          398,848
```

## Run with Docker

```bash
docker compose up --build
```

Open `http://localhost:8091`.

Stop the service:

```bash
docker compose down
```

## Run Locally

Requirements:

- Python 3.11 or newer;
- CPU-compatible PyTorch.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e ".[dev]"
python3 -m full_add_demo
```

Then open `http://localhost:8080`.

Run verification:

```bash
python3 -m pytest -q
```

## API

- `GET /health` returns model identity and checkpoint metadata.
- `POST /api/predict` accepts a JSON object with integer fields `left` and
  `right`.
- each operand must be between `0` and `9,999,999` inclusive.
