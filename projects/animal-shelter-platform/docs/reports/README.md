# Reports

Первый рабочий формат отчетности: Excel-файл со статистикой заявок.

Текущий отчет доступен в админке на странице `Статистика` и содержит:

- сводку по заявкам за период;
- заявки по городам;
- собак и кошек по городам;
- динамику заявок по дням.

PDF-отчеты стоит добавлять следующим этапом, после утверждения состава данных. Для защиты от подделок PDF должен иметь `reportId`, дату генерации, автора и контрольную сумму содержимого.
