# Portfolio Projects

This directory contains public-safe case studies and small demonstration
projects used to support the CV.

Available presentation projects:

- [`assurance-engine-demo/`](./assurance-engine-demo/) - public-safe
  architecture snapshot of the real Node.js browser-automation platform,
  including production-like VPN/Ollama infrastructure, evidence milestones,
  promotion-oriented modeling, policy gates, and safe code examples.
- [`bawsaq-trading-bot-demo/`](./bawsaq-trading-bot-demo/) - faithful Node.js
  architecture snapshot of an experimental Telegram market assistant,
  including Telegraf, Mini App authentication, MongoDB access workflows,
  Binance market data, controlled signal lifecycles, and the explicit boundary
  before future trade execution.

- [`animal-shelter-platform/`](./animal-shelter-platform/) - runnable full-stack
  shelter operations platform with a public portal, RBAC administration,
  Prisma/MySQL persistence, synthetic demo data, and a one-command Docker
  environment.
- [`pattern-dna-research-platform/`](./pattern-dna-research-platform/) -
  large-scale computational genomics case study with multi-gigabyte derived
  datasets, approximately 7.27 million PostgreSQL rows, hundreds of analysis
  scripts, contextual role modeling, and a real PixiJS chromosome viewer.
- [`audi-a8-instrument-cluster-research/`](./audi-a8-instrument-cluster-research/) -
  reproducible automotive-electronics bench dossier with selected Arduino
  firmware, CAN/UDS evidence analysis, a Dockerized research workspace, and an
  explicit responsible-research boundary.
- [`phoenix-protocol-control-plane/`](./phoenix-protocol-control-plane/) -
  documentation-first snapshot of the real Markdown instruction architecture,
  including filesystem and Git/ChatGPT bootstrap models, layer structure,
  loading rules, publication boundaries, and 16 bounded excerpts from the
  constitution, resolver, modes, artifacts, extensions, and workflow layers.
- [`phoenix-agent-runtime-demo/`](./phoenix-agent-runtime-demo/) - faithful
  Node.js/OpenAI runtime case study with a runnable 19-module reference,
  task-package contracts, worker locking, tool policy and dispatch, response
  continuity, operations persistence, structured reports, and seven tests.
