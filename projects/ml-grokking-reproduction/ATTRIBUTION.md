# Attribution

This portfolio project reproduces the experimental setup described in:

> Alethea Power, Yuri Burda, Harri Edwards, Igor Babuschkin and Vedant Misra,
> "Grokking: Generalization Beyond Overfitting on Small Algorithmic Datasets",
> 2022.

- Paper: <https://arxiv.org/abs/2201.02177>
- Official OpenAI implementation: <https://github.com/openai/grok>
- Audited upstream commit:
  `3d64b1d8c1d595dd8ebdb7771998823f1b14c7b3`

The upstream implementation is MIT-licensed. The PyTorch implementation in
this directory was written for this reproduction and portfolio presentation.
No upstream checkpoint or dataset is redistributed: the complete arithmetic
dataset is generated deterministically by the included code.
